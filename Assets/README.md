# Application icon

`etchforge.png` is the transparent master used by Avalonia windows.
`etchforge.ico` contains 16, 24, 32, 48, 64, 128 and 256 px images and is embedded as the executable icon.
`etchforge.icns` contains macOS icon representations from 16 to 1024 px and is copied into the `.app` bundle by `scripts/package-macos.sh`.

Generated with the built-in imagegen tool. Final prompt:

> Use case: logo-brand
> Asset type: desktop application icon for EtchForge, square 1024x1024 raster master to package as ICO.
> Primary request: a green frog themed app icon. A friendly, distinctive front-facing frog head, rounded silhouette with two raised eyes, simple confident smile. Rich leaf green and sage green with dark forest green details and subtle dimensional shading, crisp polished edges. Large simple forms recognizable at 16x16 and 32x32.
> Composition: one centered frog head fills about 85% of square canvas, symmetric balanced design. Transparent background outside frog silhouette. No square tile backdrop. No text, no letters, no watermark, no extra objects. Professional desktop utility icon, warm and understated.
